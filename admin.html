One visit = one person opening a page once in a browser session (refreshing doesn't add more). Location is the country/city Cloudflare reports for the connection — approximate, and VPN users show the VPN's location. No IP addresses, cookies or names are stored. Visits from you while signed in, and from browsers with "Do Not Track" on, aren't counted. Showing up to the latest 5,000 visits.

One-time setup needed

Firestore isn't allowing the visits collection yet. In the Firebase console go to Firestore Database → Rules, add this block next to the existing rooms rule, and press Publish: 

match /visits/{id} {
  allow create: if request.resource.data.keys().hasOnly(
      ['ts','country','region','city','page','room','lang','device','ref'])
    && request.resource.data.ts == request.time;
  allow read: if request.auth != null;
}
